2. Unlock SSH & Flash ImmortalWrt 25.12

This software-only method works without opening the enclosure, gives you full SSH root access to back up your critical Factory partition, and installs ImmortalWrt 25.12 with the full 234 MiB Native UBI layout.

Step 1: Download Required Firmware Files

Download the latest NR3053 release from quytttb/immortalwrt-mt798x-rebase Releases and verify checksums:

  • Bootloader (FIP): immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip
  • Firmware: immortalwrt-mediatek-filogic-viettel_nr3053-squashfs-sysupgrade.itb
  • Checksums: sha256sums
sha256sum -c sha256sums --ignore-missing

Step 2: Factory Reset & Unlock SSH

  1. Connect your PC via Ethernet to a LAN port on the NR3053 (router IP: 192.168.1.1).
  2. Perform a factory reset: press and hold the Reset button for more than 10 seconds until the LED turns off and comes back on. After reset, the web admin password is the Serial Number (S/N) printed on the bottom label of the router.
  3. Clone and run quytttb/nr3053-tools:

Linux / macOS

git clone https://github.com/quytttb/nr3053-tools.git
cd nr3053-tools
pip3 install -r requirements.txt
python3 unlock_nr3053.py --password YOUR_SERIAL_NUMBER

Windows (PowerShell)

git clone https://github.com/quytttb/nr3053-tools.git
cd nr3053-tools
py -m pip install -r requirements.txt
py unlock_nr3053.py --password YOUR_SERIAL_NUMBER
Fallback: Manual config.bin Export
If the script reports that config.cgi only returns JSON, log in to the stock web UI, download config.bin manually from Backup / Restore, and pass it with --config-input (--password is still required so the script can upload the patched config): 
python3 unlock_nr3053.py --password YOUR_SERIAL_NUMBER --config-input /path/to/config.bin

Wait for the router to reboot, then log in over SSH (password after unlock is admin):

ssh root@192.168.1.1
# Password: admin

Step 3: Inspect MTD Table & Back Up Factory

Back Up Before Writing Flash
Always verify /proc/mtd and save a copy of BL2, u-boot-env, Factory, and FIP to your PC before flashing anything. Never erase Factory (mtd3 on stock ROM).

Inside the router SSH shell, verify the stock partition layout:

cat /proc/mtd
# Expected stock output:
# mtd0: 10000000 00020000 "spi0.0"      <- Full 256 MiB raw NAND
# mtd1: 00100000 00020000 "BL2"
# mtd2: 00100000 00020000 "u-boot-env"
# mtd3: 00200000 00020000 "Factory"     <- NEVER OVERWRITE
# mtd4: 00200000 00020000 "FIP"         <- Flash ImmortalWrt FIP here
# mtd5: 02000000 00020000 "firmware"
# mtd6: 02000000 00020000 "firmware2"
# mtd7: 08e00000 00020000 "rootfs_data"
# mtd8: 01800000 00020000 "rootfs_data_backup"
# mtd9: 00200000 00020000 "Factory_backup"
# mtd10: 00200000 00020000 "fip2"
# mtd11: 00000000 00020000 "reserved"

# Dump critical boot & calibration partitions to /tmp
dd if=/dev/mtd1 of=/tmp/stock_BL2.bin
dd if=/dev/mtd2 of=/tmp/stock_uboot_env.bin
dd if=/dev/mtd3 of=/tmp/stock_Factory.bin
dd if=/dev/mtd4 of=/tmp/stock_FIP.bin
sha256sum /tmp/stock_*.bin

On your PC, copy those backups off the router (add -O if OpenSSH reports a legacy SCP protocol error):

mkdir -p nr3053-backup
scp -O root@192.168.1.1:/tmp/stock_*.bin ./nr3053-backup/

Step 4: Write ImmortalWrt U-Boot FIP

From your PC, copy the verified FIP file to the router's /tmp/fip.bin:

# Run on your PC (use `scp -O` if legacy SCP is required)
scp immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip root@192.168.1.1:/tmp/fip.bin

Back in the router SSH session, confirm FIP exists (size 0x00200000 = 2 MiB) and write it:

cat /proc/mtd | grep FIP
mtd write /tmp/fip.bin FIP

Expected output:

Unlocking FIP ...
Writing from /tmp/fip.bin to FIP ...     [w]
Fallback: If /proc/mtd does not list a named FIP partition

FIP lives at physical NAND offset 0x400000 (4 MiB). With 128 KiB (131072 B) erase blocks, seek = 0x400000 / 0x20000 = 32: 

dd if=/tmp/fip.bin of=/dev/mtd0 bs=131072 seek=32 conv=sync

Flush buffers and reboot into the new ImmortalWrt U-Boot:

sync && reboot

Step 5: Install ImmortalWrt via Web Failsafe

Because the stock NAND layout above 0x600000 is flat (not Native UBI), ImmortalWrt U-Boot will automatically start in Web Failsafe mode.

Important: Use Static IP 192.168.1.254
ImmortalWrt U-Boot defaults to serverip = 192.168.1.254 (different from 192.168.1.2 used by stock U-Boot). Set your PC's Ethernet IP to 192.168.1.254/24.
  1. Set your PC static IP to 192.168.1.254 / mask 255.255.255.0 (Linux: sudo ip addr add 192.168.1.254/24 dev eth0; Windows Admin CMD: netsh interface ip set address name="Ethernet" static 192.168.1.254 255.255.255.0).
  2. Open http://192.168.1.1/ in your browser — the FIRMWARE UPDATE page appears.
  3. Select immortalwrt-mediatek-filogic-viettel_nr3053-squashfs-sysupgrade.itb and click Upload → Update.
  4. Wait ~3 minutes while U-Boot formats the 234 MiB Native UBI partition, writes the FIT image, and reboots into ImmortalWrt.
  5. Switch your PC back to DHCP and visit http://192.168.1.1/ (LuCI) or ssh root@192.168.1.1.

Future Upgrades

Once ImmortalWrt is installed, routine upgrades do not require flashing FIP or BL2 again — simply upload newer *-squashfs-sysupgrade.itb builds in LuCI under System → Backup / Flash Firmware (or via sysupgrade over SSH).

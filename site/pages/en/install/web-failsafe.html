1. Flash via Stock Web Failsafe (No SSH Required)

The stock Viettel U-Boot (2022.07-rc3) includes a built-in HTTP Web Failsafe server. You can flash a stock-compatible OpenWrt 24.10 image directly—or even install the custom ImmortalWrt U-Boot FIP—without unlocking SSH or opening the case.

Safest Path for Beginners
Flashing a stock-U-Boot-compatible OpenWrt 24.10 build leaves your original bootloader untouched, minimizes brick risk, and lets you revert to stock firmware easily.

Prerequisites

  • An Ethernet cable connected from your PC to any LAN port on the NR3053 (do not plug into WAN).
  • For OpenWrt 24.10 (keeps stock U-Boot): Download from the AIoT.IO.VN MediaFire folder:
    • First-time install: openwrt-mediatek-filogic-viettel_nr3053-stock-squashfs-factory_fix.bin
    • Fallback if bootloop occurs: openwrt-aiotiovn-mediatek-filogic-viettel_nr3053-stock-squashfs-factory.bin
  • Optional (for ImmortalWrt 25.12): Download both immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip and immortalwrt-mediatek-filogic-viettel_nr3053-squashfs-sysupgrade.itb from GitHub Releases.

Step 1: Enter Stock Web Failsafe Mode

  1. Unplug the power cable from the NR3053.
  2. Connect your PC via Ethernet to one of the LAN ports.
  3. Press and hold the MESH (WPS) button on the back of the router, then plug in the 12 V power adapter.
  4. Keep holding MESH for about 5 seconds until the front LED transitions from red to solid green, then release the button.

Step 2: Set a Static IP on Your PC

Assign your PC Ethernet interface the static IPv4 address 192.168.1.2/24 (gateway and DNS blank):

Linux

# Replace eth0 with your actual Ethernet interface name (check with `ip link`)
sudo ip addr flush dev eth0
sudo ip addr add 192.168.1.2/24 dev eth0
sudo ip link set eth0 up

Windows

Either open Win+R → ncpa.cpl → Ethernet Properties → IPv4 → Static IP 192.168.1.2, Subnet Mask 255.255.255.0 (leave Gateway & DNS blank), or run in an Administrator Command Prompt:

netsh interface ip set address name="Ethernet" static 192.168.1.2 255.255.255.0

Step 3: Upload & Flash OpenWrt 24.10

  1. Open an incognito/private browser window and go to http://192.168.1.1/. You should see the stock U-Boot FIRMWARE UPDATE screen.
  2. Click Choose File, select openwrt-mediatek-filogic-viettel_nr3053-stock-squashfs-factory_fix.bin, and click Upload.
  3. Verify the displayed file size and MD5 checksum, then click Update.
  4. Do not unplug power while flashing. The router will reboot automatically into OpenWrt.
  5. Restore your PC Ethernet adapter back to Automatic (DHCP), then open http://192.168.1.1/ to configure OpenWrt LuCI.

Optional: Flash ImmortalWrt U-Boot FIP via /uboot.html

Caution When Replacing Bootloader
Flashing an incompatible or corrupted .fip file will prevent booting from NAND and require 3.3 V UART recovery. Verify the file with sha256sum -c sha256sums first!

If you want the full 234 MiB Native UBI layout and ImmortalWrt 25.12 without unlocking SSH, stock Web Failsafe exposes a hidden bootloader upload page:

  1. While in Stock Web Failsafe, browse to http://192.168.1.1/uboot.html.
  2. Upload immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip and click Update.
  3. After reboot, the new ImmortalWrt U-Boot starts and automatically enters Web Failsafe because no UBI OS exists yet.
  4. Change your PC static IP to 192.168.1.254/24, open http://192.168.1.1/, upload immortalwrt-mediatek-filogic-viettel_nr3053-squashfs-sysupgrade.itb, and wait ~3 minutes for the router to reboot into ImmortalWrt.
Web Failsafe Not Responding?
Some older NR3053 stock batches do not include Web Failsafe in U-Boot. If http://192.168.1.1/ does not load after holding MESH, proceed to Method 2: Unlock SSH & Flash ImmortalWrt.

3. UART Recovery & TFTP Boot

Because the NR3053 has an exposed, clearly labeled 4-pin UART header and an immutable MediaTek BootROM, you can safely test initramfs-recovery.itb in RAM without touching NAND, or completely unbrick a router with a bad U-Boot or BL2 using mtk_uartboot.

UART Wiring & Serial Settings

3.3 V TTL Only — Never Connect VCC
Use a 3.3 V USB-to-TTL serial adapter (e.g., CP2102, FT232RL, CH340 set to 3.3 V). Never use 5 V logic, and leave the router's VCC pin unconnected. Cross TX and RX: Adapter TX → Board RX, Adapter RX → Board TX, Adapter GND → Board GND.

Step 1: Prepare TFTP Server & Static IP

Connect an Ethernet cable from your PC to a LAN port on the NR3053 (leave WAN unplugged), and set your PC static IP to 192.168.1.254/24 (no gateway, no DNS, VPN off).

Linux (tftpd-hpa + picocom)

sudo apt install tftpd-hpa picocom
sudo mkdir -p /srv/tftp
# Copy .itb / .fip / .bin files into /srv/tftp, ensure /etc/default/tftpd-hpa uses TFTP_DIRECTORY="/srv/tftp"
sudo systemctl restart tftpd-hpa

sudo ip addr flush dev eth0
sudo ip addr add 192.168.1.254/24 dev eth0
sudo ip link set eth0 up

Windows (Tftpd64 + PuTTY)

  • Download Tftpd64, run as Administrator, and allow it through Windows Firewall (UDP port 69).
  • In the Tftp Server tab, set Current Directory to the folder containing your firmware files and Server interfaces to the LAN adapter with IP 192.168.1.254 (not 127.0.0.1).
  • Configure a saved PuTTY Serial session: your COM port (check Device Manager), speed 115200, 8N1, Flow control None.

Step 2: RAM-Boot U-Boot via mtk_uartboot (Unbrick)

If U-Boot on NAND is intact, simply open picocom -b 115200 /dev/ttyUSB0 (or PuTTY), power on the router, and press any key at Hit any key to stop autoboot.

If the router is bricked (only BootROM or silent serial), use mtk_uartboot (Windows/Linux releases) with the NR3053 RAM BL2 payload bl2-viettel-nr3053-ram.bin (from quytttb/bl-mt798x-dhcpd Releases) and immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip.

Two-Window Workflow (Only One App Can Hold the Serial Port)
Place two windows side by side: Window 1 for mtk_uartboot and Window 2 for picocom / PuTTY (prepared, not yet connected). As soon as Window 1 prints FIP received, press Ctrl+C in Window 1 and immediately connect Window 2 within 1–2 seconds!

Linux Command

# Window 2 (ready, DO NOT press Enter yet):
#   sudo picocom -b 115200 /dev/ttyUSB0

# Window 1 (unplug router first, run command, then plug power in on "Handshake..."):
sudo ./mtk_uartboot -s /dev/ttyUSB0 \
  -p bl2-viettel-nr3053-ram.bin \
  -f immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip \
  -a

Windows Command (CMD)

mtk_uartboot.exe -s COM3 -p bl2-viettel-nr3053-ram.bin -a -f immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip

If your USB-TTL adapter hangs at 921600 baud, append --bl2-load-baudrate 115200. Remember that mtk_uartboot runs U-Boot entirely in RAM without modifying NAND until you write partitions yourself.

Option A: Boot initramfs-recovery.itb in RAM (Non-Destructive)

Place immortalwrt-mediatek-filogic-viettel_nr3053-initramfs-recovery.itb in your TFTP folder, then in U-Boot either run bootmenu → [2] Boot system via TFTP or type:

setenv serverip 192.168.1.254
setenv ipaddr   192.168.1.1
tftpboot 0x46000000 immortalwrt-mediatek-filogic-viettel_nr3053-initramfs-recovery.itb
bootm 0x46000000#config-1

ImmortalWrt boots cleanly in RAM. Power-cycling reverts the router to whatever is stored in NAND.

Option B: Permanent Install & Bootloader Recovery

Place immortalwrt-mediatek-filogic-viettel_nr3053-squashfs-sysupgrade.itb in your TFTP folder. In U-Boot, run bootmenu → [5] Load production system via TFTP then write to NAND, or manually:

setenv serverip 192.168.1.254
setenv ipaddr   192.168.1.1
tftpboot 0x46000000 immortalwrt-mediatek-filogic-viettel_nr3053-squashfs-sysupgrade.itb

ubi part ubi
ubi check fit && ubi remove fit
ubi create fit $filesize dynamic
ubi write 0x46000000 fit $filesize
ubi read 0x46000000 fit && bootm 0x46000000#config-1

Re-Flashing FIP (or BL2) Over TFTP

# Restore/upgrade FIP (bootmenu [7])
tftpboot 0x46000000 immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip
mtd erase FIP
mtd write FIP 0x46000000

# Only if BL2 on NAND is corrupted or incompatible (bootmenu [8] — HIGH RISK)
tftpboot 0x46000000 immortalwrt-mediatek-filogic-viettel_nr3053-preloader.bin
mtd erase BL2
mtd write BL2 0x46000000

Clearing Legacy NMBM Conflicts

If UBI fails to attach due to a leftover stock NMBM table, format the UBI partition from the U-Boot console:

ubi part ubi
run ubi_format

The router resets automatically; then re-run Option B (or Web Failsafe) to write the firmware.

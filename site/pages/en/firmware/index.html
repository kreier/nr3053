1. ImmortalWrt 25.12 (quytttb/immortalwrt-mt798x-rebase)

Maintained by quytttb, this fork targets mediatek/filogic (Linux 6.12) and publishes verified pre-built images with sha256sums on GitHub Releases (latest: v2.5.0, 2026-10-30).

USB Hardware Mod Note
Release v2.5.0 includes USB support specifically for NR3053 units that have had a physical USB hardware mod soldered onto the PCB. Unmodified NR3053 boards work normally (the USB controller stays unused), or you can check earlier releases such as v2.4.5. Always verify downloads with sha256sum -c sha256sums.

2. OpenWrt 24.10 for Stock U-Boot (aiot.io.vn)

Built by Ng Nghia Phan (AIoT.IO.VN) to match the stock Viettel U-Boot layout so you can install OpenWrt in minutes without unlocking SSH or replacing the bootloader (official upstream OpenWrt 25.12 support for NR3053 is not yet merged).

  • Download folder: MediaFire — NR3053 OpenWrt 24.10 (linked from the AIoT.IO.VN No-SSH Guide)
  • Primary image (first-time flash): openwrt-mediatek-filogic-viettel_nr3053-stock-squashfs-factory_fix.bin
  • Fallback image (if bootloop occurs): openwrt-aiotiovn-mediatek-filogic-viettel_nr3053-stock-squashfs-factory.bin
  • Packages: Compatible with official OpenWrt 24.10 repositories via opkg install.

3. KeeneticOS 5.01 DIY Port (linhsayshii/keeneticos-nr3053)

An experimental port of KeeneticOS 5.01.C.7.0-4 (KN-3811) onto the Viettel NR3053 by linhsayshii. Because Keenetic's ndm daemon, web UI, and drivers are proprietary, the repository does not distribute compiled firmware binaries — it provides kernel 4.9 patches (including the Dosilicon DS35Q2GBS SPI-NAND driver using read command 0x6B), binary patches for 4-port MT7531 Ethernet and NR3053 GPIOs, and open-source dual-image bootloaders (Release v32). 

# Build KeeneticOS locally on Ubuntu 24.04 (ext4 filesystem, non-root user)
git clone --depth 1 -b 5.01.C.7.0-4 https://github.com/keenetic/keenetic-sdk.git
git clone https://github.com/linhsayshii/keeneticos-nr3053.git
cd keeneticos-nr3053
./scripts/apply-to-sdk.sh ../keenetic-sdk /path/to/KN-3811_stable_5.01.C.7.0-4.bin
cd ../keenetic-sdk && make -j$(nproc)
python3 ../keeneticos-nr3053/tools/verify_fw.py bin/mt7981/*_Firmware-KN-3811-5.01.C.7.0-4.bin

Note: Auto-updates are disabled (official KN-3811 images will not boot on NR3053), and upgrades are flashed through U-Boot Web Failsafe.

4. Roadmap: Official Upstream OpenWrt (ubootmod)

Because all core hardware (MT7981BA, MT7976CN, MT7531AE, DS35Q2GBS) is already supported by mainline Linux and OpenWrt mediatek/filogic, the NR3053 is a strong candidate for an official upstream viettel_nr3053 (ubootmod + single 234 MiB Native UBI with built-in recovery volume) PR to openwrt/openwrt.

See the complete 8-step development, UART RAM-boot test, stock-revert, and PR submission guide in docs/upstream-openwrt-roadmap.md.

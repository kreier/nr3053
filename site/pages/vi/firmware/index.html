Các lựa chọn Firmware cho Viettel SDMC NR3053

Hiện có 3 dòng firmware cộng đồng hoạt động ổn định cho NR3053. Hãy chọn phiên bản phù hợp với nhu cầu sử dụng, kho gói cài đặt và việc bạn muốn giữ hay thay bootloader gốc.

1. ImmortalWrt 25.12 (quytttb/immortalwrt-mt798x-rebase)

Do quytttb duy trì trên nhánh mediatek/filogic (Linux 6.12) với đầy đủ file build sẵn kèm mã kiểm tra sha256sums tại GitHub Releases (bản mới nhất: v2.5.0, 30/10/2026).

Lưu ý về tính năng USB Mod
Bản phát hành v2.5.0 bật hỗ trợ USB dành riêng cho các máy NR3053 đã mod phần cứng cổng USB. Máy NR3053 nguyên bản vẫn chạy bình thường (bộ điều khiển USB không dùng đến), hoặc bạn có thể tham khảo bản v2.4.5. Luôn kiểm tra tính toàn vẹn file bằng sha256sum -c sha256sums.

2. OpenWrt 24.10 cho U-Boot gốc (aiot.io.vn)

Do Ng Nghia Phan (AIoT.IO.VN) biên dịch tương thích hoàn toàn với U-Boot gốc của Viettel giúp người dùng cài nhanh mà không phải mở SSH hay thay đổi bootloader (OpenWrt chính thức hiện chưa có nhánh 25.12 cho NR3053).

  • Thư mục tải về: MediaFire — NR3053 OpenWrt 24.10 (từ bài viết AIoT.IO.VN)
  • File khuyến nghị (lần đầu flash): openwrt-mediatek-filogic-viettel_nr3053-stock-squashfs-factory_fix.bin
  • File dự phòng (nếu gặp bootloop): openwrt-aiotiovn-mediatek-filogic-viettel_nr3053-stock-squashfs-factory.bin
  • Kho gói: Tương thích kho gói chính thức OpenWrt 24.10, dùng opkg install trực tiếp.

3. Bản Port tự build KeeneticOS 5.01 (linhsayshii/keeneticos-nr3053)

Dự án port KeeneticOS 5.01.C.7.0-4 (mã KN-3811) lên NR3053 của linhsayshii. Do phần mềm ndm, giao diện web và driver của Keenetic là mã nguồn đóng, kho GitHub không phân phối file firmware sẵn — mà cung cấp trọn bộ bản vá kernel 4.9 (gồm driver SPI-NAND Dosilicon DS35Q2GBS dùng lệnh đọc 0x6B), script vá nhị phân cho 4 cổng MT7531/GPIO NR3053 và bootloader mã nguồn mở (Release v32). 

# Tự build KeeneticOS trên Ubuntu 24.04 (filesystem ext4, user không phải root)
git clone --depth 1 -b 5.01.C.7.0-4 https://github.com/keenetic/keenetic-sdk.git
git clone https://github.com/linhsayshii/keeneticos-nr3053.git
cd keeneticos-nr3053
./scripts/apply-to-sdk.sh ../keenetic-sdk /duong/dan/KN-3811_stable_5.01.C.7.0-4.bin
cd ../keenetic-sdk && make -j$(nproc)
python3 ../keeneticos-nr3053/tools/verify_fw.py bin/mt7981/*_Firmware-KN-3811-5.01.C.7.0-4.bin

Lưu ý: Tính năng auto-update đã bị tắt (firmware KN-3811 chính hãng không chạy trên NR3053); mọi nâng cấp đều nạp qua U-Boot Web Failsafe.

4. Lộ trình hỗ trợ OpenWrt chính thức (ubootmod)

Toàn bộ phần cứng lõi (MT7981BA, MT7976CN, MT7531AE, DS35Q2GBS) đều đã có driver sẵn trên nhánh mediatek/filogic của OpenWrt chính thức, nên NR3053 hoàn toàn có thể đóng góp PR hỗ trợ chính thức theo chuẩn ubootmod (một vùng Native UBI 234 MiB kèm volume recovery tích hợp sẵn trong NAND).

Xem lộ trình 8 bước đầy đủ (test RAM qua UART, cấu hình U-Boot/DTS, khôi phục ROM gốc và gửi PR lên openwrt/openwrt) tại docs/upstream-openwrt-roadmap.md.

Tối ưu Wi-Fi Roaming (802.11r/k/v) & SQM Chống Bufferbloat

Hướng dẫn tinh chỉnh sau cài đặt cho ImmortalWrt 25.12 trên Viettel SDMC NR3053 (tham khảo từ gist tối ưu NR3053 của hashcott) giúp chuyển vùng mượt giữa 2.4 GHz ↔ 5 GHz và đạt Bufferbloat Grade A trên Waveform.

Bước 1: Cài gói SQM & Kiểm tra wpad đầy đủ

ImmortalWrt 25.12 sử dụng trình quản lý gói apk. Kết nối ssh root@192.168.1.1 và cài SQM: 

apk update
apk add luci-app-sqm sqm-scripts

Chuyển vùng nhanh (802.11r/k/v) yêu cầu gói wpad bản đầy đủ (wpad-openssl hoặc wpad-mbedtls), không phải wpad-basic-*. ImmortalWrt 25.12 trên MT7981 thường có sẵn wpad-openssl; kiểm tra bằng: 

apk info | grep wpad
# Nếu chỉ thấy wpad-basic-*, hãy thay bằng bản full:
# apk del wpad-basic-mbedtls && apk add wpad-openssl && reboot

Bước 2: Cấu hình Wi-Fi + Roaming 802.11r/k/v

Đặt cùng tên SSID và mật khẩu cho cả 2.4 GHz và 5 GHz với chuẩn mã hóa WPA2 (psk2, tương thích roaming ổn định nhất trên mọi điện thoại/laptop), kênh 5 GHz không DFS (36, HE80) và kênh 2.4 GHz ít nhiễu (6, HE20). Sửa 2 dòng SSID/PASS rồi dán vào SSH: 

# ==== ĐIỀN THÔNG TIN WIFI CỦA BẠN ====
SSID="TenWifi_CuaBan"
PASS="MatKhauItNhat8KyTu"
# =====================================

for i in $(uci show wireless | grep "=wifi-iface" | cut -d= -f1); do
  uci set $i.ssid="$SSID"
  uci set $i.key="$PASS"
  uci set $i.encryption='psk2'          # WPA2 — tương thích 802.11r tốt nhất
  uci set $i.ieee80211r='1'             # Fast Transition (802.11r)
  uci set $i.ft_over_ds='0'
  uci set $i.ft_psk_generate_local='1'
  uci set $i.mobility_domain='a1b2'     # Phải giống nhau ở cả 2 băng tần
  uci set $i.ieee80211k='1'             # RRM (802.11k)
  uci set $i.bss_transition='1'         # BSS Transition (802.11v)
  uci set $i.disassoc_low_ack='0'       # Không tự đá thiết bị tín hiệu yếu
  uci -q delete $i.ocv
done

for r in $(uci show wireless | grep "=wifi-device" | cut -d= -f1); do
  band=$(uci -q get $r.band)
  uci set $r.disabled='0'
  if [ "$band" = "2g" ]; then
    uci set $r.channel='6'              # Kênh 2.4 GHz ít chồng lấn (1/6/11)
    uci set $r.htmode='HE20'            # 20 MHz ổn định nhất ở 2.4 GHz
  elif [ "$band" = "5g" ]; then
    uci set $r.channel='36'             # Kênh 5 GHz không DFS (36/40/44/48)
    uci set $r.htmode='HE80'            # 80 MHz cân bằng tốc độ và độ ổn định
  fi
done

uci commit wireless
wifi reload

Kiểm tra cả hai băng tần đã nhận đủ tham số roaming:

uci show wireless | grep -E "ssid|encryption|ieee80211r|ieee80211k|bss_transition|mobility"
iwinfo

Bước 3: Cấu hình SQM/cake chống Bufferbloat

Trước tiên xác định tên cổng WAN của bạn (thường là wan hoặc pppoe-wan):

ip route show default
Ngưỡng hiệu năng CPU MT7981 với SQM/cake
cake xử lý trên CPU (đơn luồng mỗi chiều). Với MT7981B, cake chạy ổn định ở mức ~250–300 Mbps mỗi chiều. Hãy đặt băng thông bằng ~85–90% tốc độ gói mạng và giới hạn quanh 250–300 Mbps để giữ sirq dưới ~30%. 
[ -z "$(uci -q show sqm.@queue[0])" ] && uci add sqm queue >/dev/null
uci set sqm.@queue[0].enabled='1'
uci set sqm.@queue[0].interface='wan'        # Đổi thành pppoe-wan nếu quay PPPoE
uci set sqm.@queue[0].download='250000'      # kbit/s (250 Mbps — chỉnh theo mạng nhà bạn)
uci set sqm.@queue[0].upload='300000'        # kbit/s (300 Mbps)
uci set sqm.@queue[0].qdisc='cake'
uci set sqm.@queue[0].script='piece_of_cake.qos'
uci set sqm.@queue[0].linklayer='ethernet'
uci set sqm.@queue[0].overhead='44'
uci commit sqm
/etc/init.d/sqm enable
/etc/init.d/sqm restart

Tắt Flow Offloading (Bắt buộc khi dùng SQM)

Flow offloading phần mềm và phần cứng sẽ bỏ qua hàng đợi SQM — cần tắt cả hai để cake hoạt động thật sự:

uci set firewall.@defaults[0].flow_offloading='0'
uci set firewall.@defaults[0].flow_offloading_hw='0'
uci commit firewall
/etc/init.d/firewall restart

# Xác nhận cake đang chạy trên cả 2 chiều (dev wan và dev ifb4wan)
tc qdisc show | grep cake

Bước 4: Tinh chỉnh & Kiểm chứng điểm A

  1. Chạy kiểm tra tại Waveform Bufferbloat Test đồng thời mở SSH khác gõ top -d 1.
  2. Mục tiêu: độ trễ tăng thêm khi có tải (Download/Upload Active) < +20 ms và CPU idle > 15–20% (sirq < 30%).
  3. Nếu chiều nào tăng trễ cao, giảm băng thông chiều đó đi 20–30 Mbps (ví dụ: uci set sqm.@queue[0].download='250000' && uci commit sqm && /etc/init.d/sqm restart) rồi đo lại.

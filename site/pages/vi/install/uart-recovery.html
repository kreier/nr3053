3. Cứu Brick qua UART & Nạp Firmware TFTP

Nhờ có sẵn cụm 4 chân UART in nhãn rõ ràng và BootROM cố định trong chip MediaTek, bạn có thể chạy thử initramfs-recovery.itb hoàn toàn trên RAM mà không động đến NAND, hoặc cứu sống hoàn toàn máy bị lỗi U-Boot / BL2 bằng mtk_uartboot.

Bước 1: Thiết lập TFTP Server & IP tĩnh

Cắm dây mạng từ máy tính vào cổng LAN của NR3053 (không cắm WAN) và đặt IP tĩnh máy tính là 192.168.1.254/24 (để trống Gateway/DNS, tắt VPN).

Linux (tftpd-hpa + picocom)

sudo apt install tftpd-hpa picocom
sudo mkdir -p /srv/tftp
# Chép file .itb / .fip / .bin vào /srv/tftp, chỉnh TFTP_DIRECTORY="/srv/tftp" trong /etc/default/tftpd-hpa
sudo systemctl restart tftpd-hpa

sudo ip addr flush dev eth0
sudo ip addr add 192.168.1.254/24 dev eth0
sudo ip link set eth0 up

Windows (Tftpd64 + PuTTY)

  • Tải Tftpd64, chạy bằng quyền Administrator và cho phép qua Windows Firewall (cổng UDP 69).
  • Ở tab Tftp Server, chọn Current Directory tới thư mục chứa firmware và Server interfaces là card mạng đang đặt IP 192.168.1.254 (không chọn 127.0.0.1).
  • Lưu sẵn một session PuTTY chế độ Serial: cổng COM tương ứng (xem Device Manager), tốc độ 115200, 8N1, Flow control None.

Bước 2: Nạp U-Boot vào RAM bằng mtk_uartboot (Cứu Brick)

Nếu U-Boot trên NAND vẫn chạy bình thường, bạn chỉ cần mở picocom -b 115200 /dev/ttyUSB0 (hoặc PuTTY), bật nguồn router và nhấn phím bất kỳ khi thấy Hit any key to stop autoboot.

Nếu máy bị brick (chỉ chạy BootROM hoặc im lặng), dùng mtk_uartboot (bản Windows/Linux) cùng BL2 RAM payload bl2-viettel-nr3053-ram.bin (từ quytttb/bl-mt798x-dhcpd Releases) và immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip.

Bố cục 2 cửa sổ (Tại mỗi thời điểm chỉ 1 phần mềm chiếm cổng Serial)
Đặt sẵn 2 cửa sổ cạnh nhau: Cửa sổ 1 chạy mtk_uartboot và Cửa sổ 2 gõ sẵn picocom / mở sẵn PuTTY (chưa bấm Enter / Open). Ngay khi Cửa sổ 1 hiện FIP received, bấm Ctrl+C ở Cửa sổ 1 rồi mở ngay Cửa sổ 2 trong vòng 1–2 giây!

Lệnh trên Linux

# Cửa sổ 2 (gõ sẵn, CHƯA bấm Enter):
#   sudo picocom -b 115200 /dev/ttyUSB0

# Cửa sổ 1 (rút nguồn trước, chạy lệnh rồi cắm nguồn khi thấy "Handshake..."):
sudo ./mtk_uartboot -s /dev/ttyUSB0 \
  -p bl2-viettel-nr3053-ram.bin \
  -f immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip \
  -a

Lệnh trên Windows (CMD)

mtk_uartboot.exe -s COM3 -p bl2-viettel-nr3053-ram.bin -a -f immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip

Nếu mạch USB-TTL bị treo ở tốc độ 921600, thêm cờ --bl2-load-baudrate 115200. Lưu ý mtk_uartboot chỉ nạp U-Boot vào RAM, không tự ý ghi đè lên NAND.

Tùy chọn A: Boot thử initramfs-recovery.itb trên RAM

Đặt file immortalwrt-mediatek-filogic-viettel_nr3053-initramfs-recovery.itb vào thư mục TFTP. Trong U-Boot gõ bootmenu → chọn [2] Boot system via TFTP, hoặc chạy thủ công:

setenv serverip 192.168.1.254
setenv ipaddr   192.168.1.1
tftpboot 0x46000000 immortalwrt-mediatek-filogic-viettel_nr3053-initramfs-recovery.itb
bootm 0x46000000#config-1

ImmortalWrt sẽ chạy hoàn toàn trên RAM; rút điện cắm lại máy sẽ trở về trạng thái cũ trên NAND.

Tùy chọn B: Cài đặt vĩnh viễn vào NAND & Phục hồi Bootloader

Đặt file immortalwrt-mediatek-filogic-viettel_nr3053-squashfs-sysupgrade.itb vào thư mục TFTP. Trong U-Boot gõ bootmenu → chọn [5] Load production system via TFTP then write to NAND, hoặc lệnh thủ công:

setenv serverip 192.168.1.254
setenv ipaddr   192.168.1.1
tftpboot 0x46000000 immortalwrt-mediatek-filogic-viettel_nr3053-squashfs-sysupgrade.itb

ubi part ubi
ubi check fit && ubi remove fit
ubi create fit $filesize dynamic
ubi write 0x46000000 fit $filesize
ubi read 0x46000000 fit && bootm 0x46000000#config-1

Ghi lại FIP (hoặc BL2) qua TFTP

# Phục hồi/nâng cấp FIP (bootmenu [7])
tftpboot 0x46000000 immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip
mtd erase FIP
mtd write FIP 0x46000000

# Chỉ làm khi BL2 trên NAND bị lỗi (bootmenu [8] — RỦI RO CAO)
tftpboot 0x46000000 immortalwrt-mediatek-filogic-viettel_nr3053-preloader.bin
mtd erase BL2
mtd write BL2 0x46000000

Xử lý xung đột bảng NMBM cũ

Nếu UBI không gắn được do còn sót bảng NMBM từ firmware cũ, hãy định dạng lại vùng UBI ngay trong console U-Boot:

ubi part ubi
run ubi_format

Router sẽ tự khởi động lại, sau đó bạn tiến hành Tùy chọn B (hoặc Web Failsafe) như bình thường.

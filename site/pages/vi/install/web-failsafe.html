1. Flash qua Web Failsafe gốc (Không cần mở SSH)

U-Boot gốc của Viettel NR3053 (2022.07-rc3) có tích hợp sẵn giao diện Web Failsafe. Nhờ đó bạn có thể nạp trực tiếp bản OpenWrt 24.10 tương thích U-Boot gốc—hoặc nạp file FIP U-Boot ImmortalWrt—mà không cần mở SSH hay tháo vỏ router.

Cách an toàn nhất cho người mới
Nạp bản OpenWrt 24.10 tương thích U-Boot gốc giúp giữ nguyên bootloader của nhà sản xuất, hạn chế tối đa rủi ro brick và dễ dàng quay về ROM gốc khi cần.

Chuẩn bị

  • Cáp mạng Ethernet cắm từ máy tính vào một cổng LAN bất kỳ trên NR3053 (không cắm cổng WAN).
  • Cho OpenWrt 24.10 (giữ U-Boot gốc): Tải từ thư mục MediaFire của AIoT.IO.VN:
    • Lần đầu flash: openwrt-mediatek-filogic-viettel_nr3053-stock-squashfs-factory_fix.bin
    • Dự phòng nếu không boot / bootloop: openwrt-aiotiovn-mediatek-filogic-viettel_nr3053-stock-squashfs-factory.bin
  • Tùy chọn (nếu muốn lên ImmortalWrt 25.12): Tải cả immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip và immortalwrt-mediatek-filogic-viettel_nr3053-squashfs-sysupgrade.itb từ GitHub Releases.

Bước 1: Đưa router vào chế độ Web Failsafe gốc

  1. Rút dây nguồn khỏi NR3053.
  2. Cắm dây LAN từ máy tính vào một cổng LAN bất kỳ trên router.
  3. Nhấn giữ nút MESH (WPS) ở mặt sau router rồi cắm nguồn điện 12 V vào.
  4. Tiếp tục giữ nút MESH khoảng 5 giây cho tới khi đèn mặt trước chuyển từ màu đỏ sang màu xanh lá đứng yên thì nhả tay.

Bước 2: Đặt IP tĩnh trên máy tính

Gán cho card mạng Ethernet địa chỉ IPv4 tĩnh 192.168.1.2/24 (để trống Gateway và DNS):

Linux

# Thay eth0 bằng tên cổng mạng thật (kiểm tra bằng lệnh `ip link`)
sudo ip addr flush dev eth0
sudo ip addr add 192.168.1.2/24 dev eth0
sudo ip link set eth0 up

Windows

Nhấn Win+R → gõ ncpa.cpl → chuột phải cổng Ethernet → Properties → IPv4 → nhập IP 192.168.1.2, Subnet Mask 255.255.255.0 (Gateway & DNS để trống), hoặc chạy CMD bằng quyền Administrator:

netsh interface ip set address name="Ethernet" static 192.168.1.2 255.255.255.0

Bước 3: Tải lên & Nạp OpenWrt 24.10

  1. Mở trình duyệt (nên dùng tab ẩn danh để tránh lưu cache) và truy cập http://192.168.1.1/ — màn hình FIRMWARE UPDATE của U-Boot gốc sẽ hiện ra.
  2. Nhấn Choose File, chọn file openwrt-mediatek-filogic-viettel_nr3053-stock-squashfs-factory_fix.bin rồi bấm Upload.
  3. Kiểm tra dung lượng và mã MD5 checksum hiển thị, sau đó nhấn Update.
  4. Tuyệt đối không rút nguồn trong lúc đang ghi NAND. Router sẽ tự khởi động lại vào OpenWrt khi xong.
  5. Chuyển card mạng máy tính về lại chế độ nhận IP tự động (DHCP) rồi vào http://192.168.1.1/ để cấu hình LuCI.

Tùy chọn: Nạp FIP U-Boot ImmortalWrt qua /uboot.html

Cẩn trọng khi thay đổi Bootloader
Nạp file .fip lỗi hoặc sai thiết bị sẽ khiến máy không boot được từ NAND và phải cứu qua UART 3.3 V. Hãy luôn kiểm tra file bằng sha256sum -c sha256sums trước!

Nếu muốn dùng toàn bộ 234 MiB Native UBI và chạy ImmortalWrt 25.12 mà không cần mở SSH, Web Failsafe gốc có trang ẩn để nạp bootloader:

  1. Khi đang ở Web Failsafe gốc, truy cập http://192.168.1.1/uboot.html.
  2. Chọn file immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip và nhấn Update.
  3. Sau khi khởi động lại, U-Boot ImmortalWrt mới chạy và tự động vào Web Failsafe do vùng UBI chưa có hệ điều hành.
  4. Đổi IP tĩnh máy tính sang 192.168.1.254/24, mở http://192.168.1.1/, tải lên file immortalwrt-mediatek-filogic-viettel_nr3053-squashfs-sysupgrade.itb và đợi ~3 phút để router khởi động vào ImmortalWrt.
Không vào được Web Failsafe gốc?
Một số lô NR3053 cũ hơn có thể không hỗ trợ chế độ Web Failsafe trong U-Boot. Nếu giữ nút MESH mà không mở được http://192.168.1.1/, hãy làm theo Cách 2: Mở SSH & cài ImmortalWrt.

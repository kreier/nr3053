2. Mở khóa SSH & Cài đặt ImmortalWrt 25.12

Phương pháp thuần phần mềm không cần tháo vỏ máy, cho phép đăng nhập SSH với quyền root để sao lưu phân vùng Factory quan trọng và cài đặt ImmortalWrt 25.12 với đầy đủ 234 MiB Native UBI.

Bước 1: Tải các file firmware cần thiết

Tải bản phát hành mới nhất cho NR3053 từ quytttb/immortalwrt-mt798x-rebase Releases và kiểm tra mã băm:

  • Bootloader (FIP): immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip
  • Firmware: immortalwrt-mediatek-filogic-viettel_nr3053-squashfs-sysupgrade.itb
  • Mã kiểm tra: sha256sums
sha256sum -c sha256sums --ignore-missing

Bước 2: Factory Reset & Mở khóa SSH

  1. Cắm cáp Ethernet từ máy tính vào một cổng LAN của NR3053 (IP router mặc định: 192.168.1.1).
  2. Factory reset router: nhấn giữ nút Reset hơn 10 giây cho đến khi đèn tắt rồi sáng lại. Sau khi reset, mật khẩu trang quản trị web sẽ là Serial Number (S/N) in dưới đáy router.
  3. Clone và chạy công cụ quytttb/nr3053-tools:

Linux / macOS

git clone https://github.com/quytttb/nr3053-tools.git
cd nr3053-tools
pip3 install -r requirements.txt
python3 unlock_nr3053.py --password SERIAL_NUMBER_CUA_BAN

Windows (PowerShell)

git clone https://github.com/quytttb/nr3053-tools.git
cd nr3053-tools
py -m pip install -r requirements.txt
py unlock_nr3053.py --password SERIAL_NUMBER_CUA_BAN
Dự phòng: Tải thủ công file config.bin
Nếu script báo config.cgi chỉ trả về JSON, hãy đăng nhập trang web gốc, tải file config.bin thủ công ở mục Sao lưu / Backup rồi truyền qua tham số --config-input (vẫn giữ --password để script đăng nhập và tải ngược bản đã vá lên router): 
python3 unlock_nr3053.py --password SERIAL_NUMBER_CUA_BAN --config-input /duong/dan/config.bin

Chờ router khởi động lại xong rồi kết nối SSH (mật khẩu sau khi unlock là admin):

ssh root@192.168.1.1
# Mật khẩu: admin

Bước 3: Kiểm tra MTD & Sao lưu phân vùng Factory

Sao lưu trước khi ghi Flash
Luôn kiểm tra /proc/mtd và chép các phân vùng BL2, u-boot-env, Factory và FIP ra máy tính trước khi ghi đè. Tuyệt đối không xóa Factory (mtd3 trên ROM gốc).

Trong cửa sổ SSH của router, kiểm tra bố cục phân vùng gốc:

cat /proc/mtd
# Kết quả điển hình ROM gốc NR3053:
# mtd0: 10000000 00020000 "spi0.0"      <- Toàn bộ NAND raw 256 MiB
# mtd1: 00100000 00020000 "BL2"
# mtd2: 00100000 00020000 "u-boot-env"
# mtd3: 00200000 00020000 "Factory"     <- TUYỆT ĐỐI KHÔNG GHI
# mtd4: 00200000 00020000 "FIP"         <- Ghi FIP ImmortalWrt vào đây
# mtd5: 02000000 00020000 "firmware"
# mtd6: 02000000 00020000 "firmware2"
# mtd7: 08e00000 00020000 "rootfs_data"
# mtd8: 01800000 00020000 "rootfs_data_backup"
# mtd9: 00200000 00020000 "Factory_backup"
# mtd10: 00200000 00020000 "fip2"
# mtd11: 00000000 00020000 "reserved"

# Dump các phân vùng boot & hiệu chuẩn ra /tmp
dd if=/dev/mtd1 of=/tmp/stock_BL2.bin
dd if=/dev/mtd2 of=/tmp/stock_uboot_env.bin
dd if=/dev/mtd3 of=/tmp/stock_Factory.bin
dd if=/dev/mtd4 of=/tmp/stock_FIP.bin
sha256sum /tmp/stock_*.bin

Trên máy tính, chép các file sao lưu về cất giữ (thêm cờ -O nếu OpenSSH báo lỗi giao thức SFTP/SCP cũ):

mkdir -p nr3053-backup
scp -O root@192.168.1.1:/tmp/stock_*.bin ./nr3053-backup/

Bước 4: Ghi FIP U-Boot ImmortalWrt vào NAND

Trên máy tính, sao chép file FIP đã kiểm tra SHA-256 sang /tmp/fip.bin trên router:

# Chạy trên máy tính (dùng `scp -O` nếu máy tính yêu cầu legacy SCP)
scp immortalwrt-mediatek-filogic-viettel_nr3053-bl31-uboot.fip root@192.168.1.1:/tmp/fip.bin

Quay lại cửa sổ SSH của router, xác nhận phân vùng FIP (kích thước 0x00200000 = 2 MiB) rồi ghi:

cat /proc/mtd | grep FIP
mtd write /tmp/fip.bin FIP

Kết quả thành công:

Unlocking FIP ...
Writing from /tmp/fip.bin to FIP ...     [w]
Trường hợp ROM gốc không có tên MTD FIP trong /proc/mtd

FIP nằm tại offset vật lý 0x400000 (4 MiB). Với erase block 128 KiB (131072 B), ta có seek = 0x400000 / 0x20000 = 32: 

dd if=/tmp/fip.bin of=/dev/mtd0 bs=131072 seek=32 conv=sync

Đồng bộ bộ đệm và khởi động lại sang U-Boot ImmortalWrt:

sync && reboot

Bước 5: Nạp ImmortalWrt qua Web Failsafe

Do vùng NAND phía trên 0x600000 vẫn đang theo layout phẳng của ROM gốc (chưa có UBI hợp lệ), U-Boot ImmortalWrt sẽ tự động vào chế độ Web Failsafe.

Quan trọng: Đặt IP tĩnh 192.168.1.254
U-Boot ImmortalWrt dùng mặc định serverip = 192.168.1.254 (khác với 192.168.1.2 trên U-Boot gốc). Hãy đặt IP cổng mạng máy tính thành 192.168.1.254/24.
  1. Đặt IP tĩnh cho cổng Ethernet máy tính là 192.168.1.254 / Subnet Mask 255.255.255.0 (Linux: sudo ip addr add 192.168.1.254/24 dev eth0; Windows CMD Admin: netsh interface ip set address name="Ethernet" static 192.168.1.254 255.255.255.0).
  2. Mở trình duyệt truy cập http://192.168.1.1/ — giao diện FIRMWARE UPDATE sẽ hiện ra.
  3. Chọn file immortalwrt-mediatek-filogic-viettel_nr3053-squashfs-sysupgrade.itb rồi nhấn Upload → Update.
  4. Chờ ~3 phút để U-Boot tự định dạng phân vùng Native UBI 234 MiB, nạp ảnh FIT và tự khởi động vào ImmortalWrt.
  5. Chuyển máy tính về nhận IP tự động (DHCP) và truy cập http://192.168.1.1/ (LuCI) hoặc ssh root@192.168.1.1.

Nâng cấp firmware sau này

Khi đã chạy ImmortalWrt, các lần cập nhật sau không cần ghi lại FIP hay BL2 — chỉ cần tải file *-squashfs-sysupgrade.itb mới trong LuCI tại System → Backup / Flash Firmware (hoặc lệnh sysupgrade qua SSH).
